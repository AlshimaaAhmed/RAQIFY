# RAQIFY

### AI Requirements & Brief Generation Service

## About

**RAQIFY** is an AI-powered service that transforms user requirements into clear, structured project briefs using **LLM-powered extraction and generation**.

It supports both **initial brief generation and refinement**, turning raw requirements into organized, actionable briefs.

## Features

* Requirements extraction
* Structured brief generation
* Brief refinement
* Arabic & English text processing
* LLM-powered generation

## Technologies

`Python` · `Qwen3-32B` · `Groq` · `FastAPI` · `LLMs` · `Prompt Engineering`

## How It Works

```text
User Requirements
       ↓
Text Preprocessing
       ↓
Requirements Extraction
       ↓
LLM Generation
       ↓
Structured Project Brief
```
